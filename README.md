# Содержание
Реализованы две функции, вычисляющие произведение Кронекера двух булевых матриц над булевым кольцом с маской и без (kron_prod_with_mask, kron_prod_no_mask). Также в репозитории есть несколько примеров матриц для сравнения их производительности.
# Сборка
Собрать примеры можно с помощью команды 
~~~
make examples
~~~
Исполняемые файлы буду собраны в ./build/examples по умолчанию.

Запустить проверку линтером можно с помощью команды
~~~
make lint
~~~

Удалить все результаты сборки и объектные файлы можно командой
~~~
make clean
~~~

Запустить все примеры:
~~~
make run_all
~~~
